### Overview
The IT Ops Hub aims to centralize IT operational processes and automate common tasks.

### Installation
Follow the steps below to install the necessary dependencies:

First make sure the following tools are installed
- Java
- Maven
- Docker
- Docker compose

Then
```bash / terminal
# Clone the repository
$ git clone https://github.com/jp-nellai/it-ops-hub.git

# Change directory to the project folder
$ cd it-ops-hub/build_and_deploy

# Install dependencies
$ execute one of the scripts available on the folder depending on the OS
```
Look at the console or list down the docker containers and you can find all the relevant containers are up and running
